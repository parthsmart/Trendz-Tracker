If the website is down (4-step emergency workflow)
  1. Make a working copy first: Open the score-sheet mirror in Google Sheets and click File → Make a copy. Never type directly into the mirror sheet, because the website will overwrite it when it comes back online.
  2. Record new rounds in the copy: In each student’s tab of your copy, add new round columns (ROUND <n>, Date - dd/mm/yyyy, Score, Time) and enter scores as correct/total and times as m:ss (or leave Time blank for Flat rounds) using the exact same layout.
  3. Export modified tabs as CSV when the website returns: In your working copy, open each tab where new rounds were recorded during the outage and click File → Download → Comma Separated Values (.csv).
  4. Import back into Trendz Tracker: Go to Settings → Import (/pages/import.html), upload the CSV file for the student, preview the parsed rounds (existing rounds are skipped automatically), and click Import. Once imported, run Update score sheets now here so the read-only mirror is refreshed.
