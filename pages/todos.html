How Daily Task Ticking Works

Task completion is automatically evaluated by the database for each student today (Indian Standard Time):
• Specific Category / Drill / Module: Pick a category (Basics / Round), an Elements drill, or a Memoriad module to tick when the student completes that exact activity today.
• Section-Wide Task: Leave the second dropdown on "Any..." (or choose Flash Anzan) so the task ticks when the student completes any activity in that section today.
