How Daily Task Ticking Works

Task completion is automatically evaluated by the database for each student today (Indian Standard Time):
• Category Task: If a specific category is assigned (e.g. ADD or 1d4r), it ticks when the student records a score in that exact category today.
• Section Task: If category is left as "Any category in this section", it automatically ticks when the student completes any entry in that section today.
