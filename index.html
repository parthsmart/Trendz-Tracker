Supabase Setup Guide & Schema

Follow these 3 simple steps to connect your own Supabase project:

  1. Create a new project at supabase.com.
  2. Go to the SQL Editor, paste the complete script from supabase/schema.sql, and click Run.
  3. In Project Settings → API, copy your Project URL and anon public key into js/config.js.
  4. In Vercel or your .env, add your SUPABASE_SERVICE_ROLE_KEY for admin user creation.
